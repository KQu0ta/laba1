# Lab C Project

Два учебных проекта на C: генератор данных студентов и прототип базы данных складских поступлений.

---

## Файлы

| Файл | Описание |
|------|----------|
| `person_gen.c` | Генерация и управление массивом студентов |
| `lab_db.c` | Прототип БД поступлений товаров на склад |

---

## person_gen.c — Генератор студентов

Интерактивная консольная программа для генерации случайных данных о студентах и управления ими.

### Структуры данных

- **`person`** — студент: ФИО, дата рождения, номер группы, список предметов
- **`subject`** — предмет: название, кол-во лекций/лабораторных, аттестация (`exam` / `test` / `coursework`)

### Команды

| Команда | Описание |
|---------|----------|
| `gen N` | Сгенерировать `N` студентов |
| `get_size` | Показать размер занятой памяти |
| `print_students N` | Вывести `N` студентов (без аргумента — всех) |
| `clean` | Очистить данные и освободить память |
| `exit` | Выход из программы |

### Компиляция и запуск

```bash
gcc person_gen.c -o person_gen
./person_gen          # Linux
person_gen.exe        # Windows
```

> **Примечание:** файл использует `<windows.h>` для установки кодировки UTF-8 в консоли. При сборке на Linux — убрать `#include <windows.h>` и вызовы `SetConsoleOutputCP` / `SetConsoleCP`.

## lab_db.c — БД складских поступлений (прототип)

Прототип базы данных для учёта поступления товаров на склад.

### Структура записи

| Поле | Тип | Описание |
|------|-----|----------|
| `comes` | `time_t` | Дата поступления |
| `sender` | `char*` | Грузоотправитель |
| `name` | `char*` | Наименование товара |
| `weight` | `int` | Масса товара |
| `count` | `int` | Количество |
| `images` | `char[12]` | Значки: `fragile`, `toxic`, `perishable`, `acrid`, `inflammable`, `frozen` |
| `worker` | `char*` | Принявший работник |

### Поддерживаемые команды

| Команда | Описание |
|---------|----------|
| `insert` | Добавить запись |
| `select` | Выбрать записи |
| `delete` | Удалить записи |
| `update` | Обновить записи |
| `uniq` | Уникальные значения |

### Компиляция

```bash
gcc lab_db.c -o lab_db
./lab_db
```
